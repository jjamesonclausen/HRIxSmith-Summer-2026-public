# SimScale Forum Airfoil Validation Threads

This is a link index from a public SimScale Forum search performed on 2026-07-17. It is not a validation dataset and does not endorse the advice in any thread.

> Unverified: relevance was screened from public search results and thread titles/snippets. Read each thread, check its date and assumptions, and validate any advice against a source-matched benchmark.
