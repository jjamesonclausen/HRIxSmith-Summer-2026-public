## Advanced Concepts

SimScale allows its users to model advanced flow characteristics, like momentum sources or porous media, which would otherwise require sophisticated geometries or large meshes leading to expensive simulations. This modeling can be done using the **Advanced concepts** feature in the simulation tree:

![simulation tree advanced concepts workbench](https://frontend-assets.simscale.com/media/2020/08/advance-concepts.jpg)

Figure 1: Accessing the Advanced concepts feature inside the SimScale workbench

The options available for modeling depend on the chosen analysis type —a general description of all advanced concepts can be found below. For a list of advanced concepts available for each analysis type, please check Table 1 of this documentation page.

## List of Advanced Concepts

*Rotating zones* can be used to model rotating systems such as turbines, fans, ventilators, and similar systems. Two types are available: *MRF* (Multiple Reference Frame) and *AMI* (Arbitrary Mesh Interface).

<iframe title="“Rotating Zones” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/rotating-zones/embed/#?secret=s9xZEiZvmx#?secret=NcItMOHV4I" width="500" height="340" frameborder="0"></iframe>

*Solid body motions* can model the effect of the movement of the solid body sitting inside the fluid domain. This includes linear, rotating, and oscillating motions. Another option available within this result control is *Ship design analysis*.

<iframe title="“Solid Body Motions” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/solid-body-motions/embed/#?secret=9RcMgEYBnk#?secret=BdM5dKljXZ" width="500" height="340" frameborder="0"></iframe>

With this option, a volume within the simulation domain can be modeled as a porous medium avoiding the need for a porous geometry and subsequently a fine mesh.

> [Porous Media and Porosity Characteristics](https://www.simscale.com/docs/simulation-setup/advanced-concepts/porous-media/)

<iframe title="“Porous Media and Porosity Characteristics” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/porous-media/embed/#?secret=26Ahxv7LHx#?secret=8YEGLY4wYJ" width="500" height="282" frameborder="0"></iframe>

To model the heat generation from a volume it can be defined as a power source. *Power sources* can be assigned as either an absolute or a specific value.

> [Power Source](https://www.simscale.com/docs/simulation-setup/advanced-concepts/power-sources/)

<iframe title="“Power Source” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/power-sources/embed/#?secret=GTXLykYoNV#?secret=Jt8KnqxmPJ" width="500" height="282" frameborder="0"></iframe>

*Momentum sources* can be used to simulate fans, ventilators, and other similar devices without having to model the exact geometry and motion of the device. Two options are available within momentum sources: *Average velocity* and *Fan model*.

> [Momentum Sources](https://www.simscale.com/docs/simulation-setup/advanced-concepts/momentum-sources/)

<iframe title="“Momentum Sources” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/momentum-sources/embed/#?secret=pSKgFEKXOD#?secret=lD4oFJ3Ptz" width="500" height="282" frameborder="0"></iframe>

*Passive scalar sources* can be used to simulate the propagation of species like smoke from a burning car in a garage or the diffusion of dust or pollutants in a tunnel. This is only valid if these species get transported with the fluid without having any effect on the flow physics.

> [Passive Scalar Sources](https://www.simscale.com/docs/simulation-setup/advanced-concepts/passive-scalar-sources/)

<iframe title="“Passive Scalar Sources” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/passive-scalar-sources/embed/#?secret=HQRAtAy7az#?secret=MTYcXcdlMm" width="500" height="282" frameborder="0"></iframe>

It can be used to approximate the effect of heat sources and heat transfer from that source to the surrounding domain without explicitly having to resolve the source geometry itself.

> [Thermal Resistance Networks](https://www.simscale.com/docs/simulation-setup/advanced-concepts/thermal-resistance-networks/)

<iframe title="“Thermal Resistance Networks” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/thermal-resistance-networks/embed/#?secret=PqHASClZHr#?secret=3UcudVpzP5" width="500" height="282" frameborder="0"></iframe>

The *contact resistance* advanced concept is exclusive to the [conjugate heat transfer (IBM)](https://www.simscale.com/docs/analysis-types/conjugate-heat-transfer-ibm/) analysis type, allowing users to define additional thermal resistance to contact of interest.

> [Contact Resistance](https://www.simscale.com/docs/simulation-setup/advanced-concepts/contact-resistance/)

<iframe title="“Contact Resistance” — SimScale" src="https://www.simscale.com/docs/simulation-setup/advanced-concepts/contact-resistance/embed/#?secret=BARaRxVWry#?secret=AID0hsOsb4" width="500" height="282" frameborder="0"></iframe>

## Advanced Concepts Availability

The table below contains an overview of which advanced concepts are available for each [CFD analysis type](https://www.simscale.com/docs/analysis-types/#fluid-dynamics-openfoam):

| **Analysis Type** | **Available Advanced Concepts** |
| --- | --- |
| [Incompressible](https://www.simscale.com/docs/analysis-types/incompressible-fluid-flow-analysis/) | Momentum source, passive scalar source, porous media, rotating zone, and solid body motion (only if transient) |
| [Multi-purpose](https://www.simscale.com/docs/analysis-types/subsonic-cartesian/) | Porous media, rotating zone |
| [Compressible](https://www.simscale.com/docs/analysis-types/compressible-fluid-flow-analysis/) | Porous media, rotating zone |
| [Convective heat transfer](https://www.simscale.com/docs/analysis-types/convective-heat-transfer-analysis/) | Momentum source, passive scalar source, porous media, power source, and rotating zone |
| [Conjugate heat transfer](https://www.simscale.com/docs/analysis-types/conjugate-heat-transfer-analysis/) | Momentum source, passive scalar source, porous media, power source, thermal resistance network, and rotating zone |
| [Conjugate heat transfer (IBM)](https://www.simscale.com/docs/analysis-types/conjugate-heat-transfer-ibm/) | Momentum source, porous media, power source, contact resistance, rotating zone, thermal resistance network, and passive scalar source |
| [Multiphase](https://www.simscale.com/docs/analysis-types/multiphase-fluid-flow-analysis/) | Rotating zone, solid body motion |

Table 1: Overview of the available advanced concepts per analysis type

For [Pedestrian Wind Comfort](https://www.simscale.com/docs/analysis-types/pedestrian-wind-comfort-analysis/advanced-modelling/) and [Incompressible (LBM)](https://www.simscale.com/docs/analysis-types/incompressible-lbm/advanced-modelling-lbm/) analysis types, this feature is addressed as *Advanced modelling*.
