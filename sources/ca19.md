## Result Control

*Result control* allows users to define extra simulation result outputs. This can be a specific solution field like vorticity, calculation of forces and moments on the facade of a monument in a wind comfort simulation, or areas of high stress in a structural analysis.

In an iterative solution where the initial estimations of variables are updated per iteration one should expect to see those variables come to a level and don’t change anymore. Result control items can be a great way to [assess convergence](https://www.simscale.com/knowledge-base/how-to-check-convergence-of-a-cfd-simulation/#check-the-result-control-items) of these variables by studying the pattern in which they stabilize as the simulation progresses. This is particularly helpful in saving time and [core hours](https://www.simscale.com/knowledge-base/what-is-core-hours/) by stopping the simulation when it is not going in the desired direction.

The user can find the result control item inside the simulation tree. A general explanation of the result control settings for each type of analysis in SimScale can be seen below:

Note

Result control items are a part of simulation setup and need to be set in advance **before** the simulation is run.

## Fluid Flow Analysis

Users can find the following *Result control* settings for OpenFOAM® based [analysis](https://www.simscale.com/docs/analysis-types/#fluid-dynamics-openfoam) and [Multi-purpose analysis](https://www.simscale.com/docs/analysis-types/subsonic-cartesian/):

![available result controls in a cfd analysis which includes forces and moments, surface data, probe points and field calculations](https://frontend-assets.simscale.com/media/2026/07/Result-control-incompressible-analysis.png)

Figure 1: List of result control items in a CFD analysis

- [**Forces and moments**](https://www.simscale.com/docs/simulation-setup/result-control/forces-and-moments/): Calculates the forces and moments on a specific surface. This is used, for example, when one wants to find the drag and lift coefficient of a car surface in the aerodynamic analysis.
- [**Surface data**](https://www.simscale.com/docs/simulation-setup/result-control/surface-data/): Calculates average or an integral of the simulation results on a specified surface area.
- **Probe points**: One can place points for the measurement of the flow variables inside the model. They can be thought of as virtual hot wires, pitot tubes, or pressure taps. Users can define the probe points by creating [point](https://www.simscale.com/docs/simulation-setup/model/geometry-primitives/#point) geometry primitives and setting the coordinates of those points.
- **[Field calculations](https://www.simscale.com/docs/simulation-setup/result-control/field-calculations/)**: The user can enable additional calculations in the flow domain to explore flow characteristics. The calculations that can be done are pressure fields, turbulence, vorticity, mean age of fluid, and wall shear stress. Here it is also possible to define result controls for the pressure coefficient.

## Structural Analysis

The *Result control* settings for [structural analysis](https://www.simscale.com/docs/analysis-types/#solid-mechanics-code-aster) based on Code\_Aster can be seen below:

![available result controls in a structural analysis which includes solution fields, edge calculation, area calculation, volume calculation and point data](https://frontend-assets.simscale.com/media/2020/07/ResultControl-StructuralAnalysis-1.jpg)

Figure 2: List of result control items in a structural analysis

- **Solution fields**: Here quantities like displacements, strain and stress types, reaction forces, can be set for calculation.
- **Edge calculation**: Calculates statistical data of a chosen parameter on an edge. For example, the average displacement on an edge in the x-direction.
- **Area calculation**: This gathers statistical data of a surface in the model. For example, the minimum and maximum values of velocity in the y-direction.
- **Volume calculation**: Statistical data for a volume. For example, the sum of forces and strains in the z-direction or all directions.
- **Point data**: This is similar to *probe points* in CFD analysis where the user can define points that will be measurement points for the simulation.

To know more about the result control settings for structural simulations interested readers are requested to visit this document.

> [Result Control – Structural Analysis](https://www.simscale.com/docs/simulation-setup/result-control/result-control-structural/)

## LBM and PWC

Professional users can find the *Result control* settings for the [LBM and PWC](https://www.simscale.com/docs/analysis-types/#fluid-dynamics-lbm-solver) analysis in the list below:

![available result controls in a pwc analysis which includes forces and moments, probe points, field calculations, transient output, statistical averaging and snapshot](https://frontend-assets.simscale.com/media/2020/07/ResultControl-PWCandLBM.jpg)

Figure 3: List of result control items in LBM analysis

- **Forces and moments**: Calculates the forces and moments of a specific surface. For example, you can enable this when you want to observe the wind load on a building surface facing the predominant wind direction.
- **Probe points**: One can place points to use as measurement points in the model. Moreover, the user can enable this if there are particular areas of interest that need attention.
- **Field calculations**: Additional calculations that are done in the domain of the simulation. You can add additional calculations for vorticity, friction velocity, or surface normals.
- **Transient output**: One can export the transient output of the whole or a fraction of the simulation by controlling the write frequency. Both flow-domain and surface fields can be exported.
- **Statistical averaging**: The user can change the settings of how the statistical averaged results are exported and the settings are similar to those in the transient output. However, instead of a transient set of results, they will be averaged into one result.
- **Snapshot**: Simulation results from the last time step of the simulation are shown as a snap. It is also important to remember that this is only available for PWC simulations. The domain of the snapshot can be the same domain as the region of interest or can be defined by a geometry primitive.

Detailed information on the result control items can be found here:

> [Incompressible LBM (Lattice Boltzmann Method) Advanced Options](https://www.simscale.com/docs/incompressible-lbm-lattice-boltzmann-advanced/)

## Electromagnetic Analysis

Following result control items are available for the Electromagnetics analysis:

**Forces and torques**: Calculates forces and torques on assigned volumes based on the torque reference point.

**Probe points:** Calculates quantities like magnetic and electric flux density, magnetic field, etc., on user-defined points by creating [point](https://www.simscale.com/docs/simulation-setup/model/geometry-primitives/#point) geometry primitives.

Detailed information on the result control items can be found in the [result control section](https://www.simscale.com/docs/analysis-types/electromagnetics/#result-control) below:

> [Electromagnetics Analysis](https://www.simscale.com/docs/analysis-types/electromagnetics/)
